# Swiss Dairy Farm TypeScript App

A React + TypeScript Swiss Dairy Farm web app built with Vite.

## Features

- Working login page
- Product list
- Add to cart
- Cart total calculation
- Delivery order form
- Form validations
- Final invoice page
- Delivery fee and final total
- Cow/goat sound effect on login
- Professional Swiss dairy farm design

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- GitHub
